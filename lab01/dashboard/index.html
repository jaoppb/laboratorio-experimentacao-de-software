Laboratório de Experimentação de Software · Lab01S03

Características de Repositórios Populares no GitHub

Análise das 7 questões de pesquisa do Lab01 sobre os repositórios com maior número de estrelas do GitHub. Os números abaixo são calculados ao vivo, no navegador, a partir de unified_sample.parquet (99.984 repositórios, convertido do CSV original por scripts/csv_to_parquet.py) baixado diretamente do GitHub — nenhuma estatística fica embutida no código. Hipóteses informais consolidadas em hipoteses_informais.md.

Fonte dos dados: consulta GraphQL própria à API do GitHub (sem bibliotecas de terceiros), paginada para os repositórios de maior número de estrelas — script em lab01/src. O CSV bruto é convertido para Parquet (compressão snappy, 13,06 MB → 6,34 MB) por scripts/csv_to_parquet.py e commitado como blob normal do Git (não LFS, para que raw.githubusercontent.com sirva o binário em vez do ponteiro LFS); este dashboard busca esse arquivo direto do GitHub e usa hyparquet (instalado via npm, MIT) para decodificá-lo e recalcular todas as estatísticas das 7 RQs em JavaScript puro, no navegador. Setup local: npm install uma vez dentro de lab01/dashboard, depois sirva a pasta por HTTP (não abrir via file://) — ex.: python3 -m http.server 8000 e acesse http://localhost:8000.
